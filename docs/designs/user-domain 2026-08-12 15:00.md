작성일: 2026-08-12  
Phase: 3

---

## 구현 범위

- `GET /users/me` — 학부모 계정 정보 조회 (이름, 이메일)
- `GET /users/me/children` — 자녀 프로필 목록
- `POST /users/me/children` — 자녀 프로필 추가
- `PATCH /users/me/children/{child_id}` — 자녀 프로필 수정
- `DELETE /users/me/children/{child_id}` — 자녀 프로필 삭제

Consent 처리, birth_year 범위 검증은 이번 범위에서 제외.

## 이메일 처리

Supabase JWT payload의 `email` claim에서 추출. `core/dependencies.py`에 `get_current_user_with_email` dependency 신규 추가.

```python
async def get_current_user_with_email(
    credentials: HTTPAuthorizationCredentials = Depends(_http_bearer),
    db: AsyncSession = Depends(get_db),
) -> tuple[Parent, str]:
    payload = verify_supabase_token(credentials.credentials)
    user_id = payload.get("sub")
    email = payload.get("email")
    if not user_id or not email:
        raise UnauthorizedError("유효하지 않은 토큰입니다.")
    parent = await db.get(Parent, uuid.UUID(user_id))
    if not parent:
        raise UnauthorizedError("프로필이 등록되지 않은 사용자입니다.")
    return parent, email

CurrentUserWithEmail = Annotated[tuple[Parent, str], Depends(get_current_user_with_email)]
```

`GET /users/me`에서만 사용. 나머지 엔드포인트는 기존 `CurrentUser` 유지.

## 자녀 소유권 확인

Repository 쿼리에서 `WHERE id = child_id AND parent_id = current_user.id`로 한 번에 처리.  
`None` 반환 시 service에서 `NotFoundError` 발생. 별도 소유권 체크 없음.

## 예외 처리

| 상황 | 예외 | HTTP |
|------|------|------|
| 토큰 없음 / 만료 / 서명 불일치 | `UnauthorizedError` | 401 |
| JWT payload에 email 없음 | `UnauthorizedError("유효하지 않은 토큰입니다.")` | 401 |
| sync-profile 미등록 사용자 | `UnauthorizedError("프로필이 등록되지 않은 사용자입니다.")` | 401 |
| 없거나 다른 부모의 자녀 접근 | `NotFoundError("자녀 프로필을 찾을 수 없습니다.")` | 404 |

신규 예외 클래스 없이 기존 예외 재사용.

## 데이터 흐름

```
Router → Service → Repository → DB (AsyncSession)
```

- Router: Pydantic schema 검증, dependency injection
- Service: 비즈니스 로직 (소유권 에러 발생)
- Repository: `parent_id` 조건 포함 쿼리 전담
