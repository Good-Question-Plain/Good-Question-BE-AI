# Auth 보완 설계 — 2026-08-10

## 구현 범위

비밀번호 찾기(forgot/reset-password) + 회원탈퇴(delete account)

## 엔드포인트

| Method | Path | 설명 |
|---|---|---|
| POST | /auth/forgot-password | 비밀번호 재설정 메일 발송 |
| POST | /auth/reset-password | 새 비밀번호 설정 |
| DELETE | /auth/me | 회원탈퇴 |

## 데이터 흐름

### 비밀번호 찾기
```
forgot-password:
  이메일 존재 여부 무관하게 항상 200 반환  ← 이메일 열거 공격 방지
  존재할 때만 → OTP 생성
            → Redis SET reset:{email} TTL OTP_EXPIRE_MINUTES분
            → 비밀번호 재설정 메일 발송

reset-password:
  소셜 전용 계정(hashed_password=None) → 400 반환
  Redis GET reset:{email} → OTP 검증
  → hash_password(new_password) → UPDATE caregiver.hashed_password
  → Redis DEL reset:{email}
```

### 회원탈퇴
```
DELETE /auth/me:
  CurrentUser (JWT 인증 필수)
  → Redis DEL refresh:{user_id}
  → DELETE caregiver
```

## 보안 결정 사항

- forgot-password: 이메일 존재 여부 노출 금지 → 항상 동일 응답
- reset-password: 소셜 전용 계정은 hashed_password=None이므로 400 처리
- Redis 키: otp:{email}(회원가입)과 reset:{email}(비밀번호 재설정) 네임스페이스 분리
- 신규 환경변수 없음 — 기존 OTP_EXPIRE_MINUTES 재사용
