# PRD (Product Requirements Document)

## 1. 서비스 개요

**서비스명:** Good Question  
**서비스 유형:** AI 기반 스토리텔링 말하기 교육 서비스  
**대상:** 초등학생 (학부모 계정을 통해 이용)

### 배경 및 문제 정의

현재 디지털 교육 시장(아이스크림 홈런, 밀크T 등)은 읽기·독해 중심 콘텐츠에 집중되어 있으며, 아이들의 **말하기 능력** 발달을 위한 전문화된 서비스가 부재하다. Good Question은 스토리텔링 기반 AI 대화를 통해 이 교육 공백을 채운다.

### 핵심 가치

- 아이가 이야기 속 등장인물과 대화하며 **사고력·감정·판단력·문제해결력**을 자연스럽게 훈련
- 학부모는 자녀의 말하기 성장 과정을 리포트로 추적

---

## 2. 사용자

| 구분 | 설명 |
|------|------|
| 학부모 (Caregiver) | 계정 생성 및 자녀 프로필 관리, 리포트 열람 |
| 아이 (Child) | 스토리 진행, 음성 대화, 어휘 학습 |

---

## 3. 핵심 기능 요구사항

### 3.1 회원 및 프로필 관리

- 학부모 계정 생성: 이메일, 카카오, 구글, 네이버 소셜 로그인 지원
- 하나의 학부모 계정 하에 **다수의 자녀 프로필** 등록 가능
- 자녀 프로필 정보: 이름, 나이

### 3.2 메인 화면 (대시보드)

- 진행 중인 스토리 목록과 **이어하기** 기능 표시
- 2~3개의 추천 스토리 제안
- 하단 네비게이션 메뉴: 홈 / 스토리 / 어휘 / 마이페이지

### 3.3 스토리 탐색 및 선택

- 스토리 목록에 표시되는 정보: 썸네일, 제목, 예상 소요 시간, 핵심 주제
- 스토리 상세 화면: 소개, 배경(설정), 아이의 역할 설명
- 카테고리별 필터링 지원

### 3.4 스토리 진행 (Scene 재생)

- 씬(Scene) 단위 구성: 배경 이미지 + 등장인물
- 캐릭터 대사 내레이션 자동 재생 (오디오)
- 캐릭터 대사 다시 듣기 옵션 제공

### 3.5 음성 인터랙션

- 캐릭터 발화 완료 후 아이의 마이크 **자동 활성화**
- 아이의 음성 발화 → **STT(Speech-to-Text)** 변환
- 전송 버튼으로 최종 제출
- 대화 히스토리: 캐릭터 / 아이 발화를 명확히 구분하여 표시

### 3.6 AI 응답 분석

아이의 발화를 AI가 다음 6가지 관점으로 분석:

| 분석 항목 | 설명 |
|-----------|------|
| 사고 과정 | 아이가 어떻게 생각하는지 |
| 추론 | 논리적 연결 |
| 감정 | 감정 인식 및 표현 |
| 관점 | 다양한 시각 수용 |
| 판단 | 옳고 그름에 대한 견해 |
| 해결책 | 문제 해결 제안 |

- 학습 목표 미달성 시 → **후속 질문(Follow-up Question)** 자동 생성
- 목표 달성 또는 최대 대화 턴 도달 시 → **다음 씬으로 이동**

### 3.7 말하기 이후 활동 (Post-Speaking Activity)

1. **씬 카드 배열**: 4~5장의 씬 카드를 스토리 순서에 맞게 배열
2. **핵심 어휘 제공**: 정답 시 3~4개의 핵심 어휘(단어 + 정의 + 예문) 제공
3. **이야기 재구성**: 씬 카드와 어휘를 활용해 전체 이야기를 아이가 직접 말로 재구성

---

## 4. 부가 기능 요구사항

### 4.1 학부모 리포트

- 자녀의 말하기 결과 및 성장 과정을 시각화하여 제공
- 씬별 AI 분석 결과 요약 포함

### 4.2 어휘 저장 및 복습

- 학습한 어휘를 저장, 정의 및 예문과 함께 복습 가능

### 4.3 캐릭터 표정 반응

- 아이의 응답 내용에 따라 캐릭터의 표정이 동적으로 변화

---

## 5. 네비게이션 구조

```
홈 (대시보드)
├── 진행 중인 스토리 → 이어하기
└── 추천 스토리

스토리
├── 스토리 목록 (필터링)
└── 스토리 상세
    └── 스토리 진행 (씬 → 음성 인터랙션 → 다음 씬)
        └── 말하기 이후 활동 (씬 카드 배열 → 어휘 → 재구성)

어휘
└── 저장된 어휘 목록 및 복습

마이페이지
├── 자녀 프로필 관리
└── 학부모 리포트
```

---

## 6. 기술 연동 포인트 (AI/Backend 관점)

| 기능 | 연동 필요 |
|------|----------|
| 음성 인식 | STT API 연동 |
| AI 응답 분석 | LLM 기반 발화 분석 및 후속 질문 생성 |
| 후속 질문 생성 | 씬 목표 + 아이 발화 컨텍스트 기반 프롬프트 |
| 캐릭터 대사 재생 | TTS 또는 사전 녹음 오디오 |
| 어휘 추출 | 씬 완료 시 LLM 기반 핵심 어휘 추출 |
