# PRD (Product Requirements Document)

## 1. 서비스 개요

**서비스명:** Good Question  
**서비스 유형:** AI 기반 스토리텔링 말하기 교육 서비스  
**대상:** 초등학생 (학부모 계정을 통해 이용)

### 배경 및 문제 정의

현재 디지털 교육 시장(아이스크림 홈런, 밀크T 등)은 읽기·독해 중심 콘텐츠에 집중되어 있으며, 아이들의 **말하기 능력** 발달을 위한 전문화된 서비스가 부재하다. Good Question은 스토리텔링 기반 AI 대화를 통해 이 교육 공백을 채운다.

### 핵심 가치

- 아이가 이야기 속 등장인물과 대화하며 **사고력·감정·판단력·문제해결력**을 자연스럽게 훈련
- 학부모는 자녀의 말하기 성장 과정을 리포트로 추적

---

## 2. 사용자

| 구분 | 설명 |
|------|------|
| 학부모 (Caregiver) | 계정 생성 및 자녀 프로필 관리, 리포트 열람 |
| 아이 (Child) | 스토리 진행, 음성 대화, 어휘 학습 |

---

## 3. 핵심 기능 요구사항

### 3.1 회원 및 프로필 관리

- 학부모 계정 생성: 이메일, 카카오, 구글, 네이버 소셜 로그인 지원
- 이메일 로그인 시 비밀번호 찾기 기능 제공
- 하나의 학부모 계정 하에 **다수의 자녀 프로필** 등록 가능
- 자녀 프로필 정보: 이름, 나이
- 자녀 프로필 선택 화면: 로그인 후 아이 프로필 선택 → 서비스 진입
- 계정 설정: 학부모 계정 정보 수정
- 회원탈퇴 기능 제공

### 3.2 메인 화면 (대시보드)

- 현재 진행 중인 스토리 1편을 크게 표시 (썸네일, 제목, 진행률 바, 완료 퍼센트)
- **이어하기** 버튼으로 진행 중 스토리 즉시 재개
- 추천 스토리 3개 제안 (제목, 예상 소요 시간, 카테고리 태그)
- 우측 상단 자녀 프로필 칩: 현재 선택된 아이 이름 표시 및 전환 가능
- 하단 네비게이션 메뉴: 홈 / 이야기 / 단어장 / 마이페이지

### 3.3 스토리 탐색 및 선택

- 스토리 목록 화면 (그리드 레이아웃)
  - 카드에 표시되는 정보: 썸네일 이미지, 제목, 예상 소요 시간, 카테고리 태그
  - 카테고리별 필터링: 전체 / 우정 / 용기 / 감정 / 상상 / 모험 등
- 스토리 상세 화면
  - 카테고리 태그, 제목, 스토리 소개(설명)
  - "너는 이 이야기에서..." 박스: 아이의 역할 설명
  - 예상 시간, 등장 인물 목록
  - 시작하기 버튼

### 3.4 스토리 진행 (Scene 재생)

- 씬(Scene) 단위 구성: 배경 이미지(전체화면 반투명) + 대화 UI
- 상단: 스토리 제목, 씬 진행 표시 (예: 3/8) + 진행률 바
- 씬 상단에 **이야기 줄거리** 카드 표시 (해당 씬의 내레이션/상황 설명)
- 캐릭터 대사 다시 듣기(**다시 듣기** 버튼) 옵션 제공
- 대화 히스토리: 캐릭터 발화(말풍선)와 아이 발화(말풍선)를 구분하여 표시

### 3.5 음성 인터랙션

- 캐릭터 발화 재생 중에는 마이크 비활성 ("아직 말할 차례가 아니예요" 표시)
- 캐릭터 발화 완료 후 마이크 **자동 활성화** ("듣고 있어요" 상태 표시)
- 아이의 음성 발화 → **STT(Speech-to-Text)** 변환 후 말풍선으로 표시
- **보내기** 버튼으로 최종 제출

### 3.6 AI 응답 분석

아이의 발화를 AI가 다음 3개 영역 / 5개 항목으로 분석:

**표현 영역**

| 분석 항목 | 설명 |
|-----------|------|
| 관점과 공감 | 다른 사람의 감정을 짐작하고 공감하는 표현 |
| 감정 표현 | 감정을 나타내는 다양한 어휘 사용 |
| 상호작용 | 캐릭터의 질문에 자기 생각을 대답하는 반응 |

**논리 영역**

| 분석 항목 | 설명 |
|-----------|------|
| 생각과 이유 | 자신의 생각과 그 근거를 함께 말하는 능력 |
| 결과와 해결 | 문제 상황 파악 및 해결 방향 제시 |

- 각 항목별 잘한 점(✓)과 개선 팁(💡)을 피드백으로 제공
- 각 항목에서 아이가 실제 말한 발화 예시를 인용하여 표시
- 학습 목표 미달성 시 → **후속 질문(Follow-up Question)** 자동 생성
- 목표 달성 또는 최대 대화 턴 도달 시 → **다음 씬으로 이동**

### 3.7 단어장 (학습 리포트)

단어장 탭 진입 시 **학습 리포트** 화면으로 이동. 최근 완료한 스토리의 분석 결과를 3개 탭으로 제공:

#### 어휘 탭
- 상단: 아이의 말하기 특징 요약 문단
- 지오가 사용한 주요 어휘 (태그 형태)
- 지오가 궁금해한 어휘 (태그 형태, 단어장 연계 안내)
- 자주 사용한 표현 패턴 (인용 박스)
- 어휘 피드백 (AI 요약)

#### 표현 탭
- 관점과 공감 / 감정 표현 / 상호작용 항목별 피드백
- 각 항목: 설명 + 아이 발화 인용 + 잘한 점(✓) + 개선 팁(💡)

#### 논리 탭
- 생각과 이유 / 결과와 해결 항목별 피드백
- 각 항목: 설명 + 아이 발화 인용 + 잘한 점(✓) + 개선 팁(💡)

## 4. 부가 기능 요구사항

### 4.1 학습 리포트

- 학습 리포트 화면은 **단어장 탭**에서 접근하거나 **마이페이지 → 학습 리포트 보기** 메뉴에서 접근
- 이야기별 AI 분석 결과(어휘/표현/논리) 요약 제공

### 4.2 마이페이지

- 학부모 계정 정보 표시 (이름, 이메일)
- **우리 아이들**: 등록된 자녀 프로필 목록 + 수정 버튼 + 아이 추가하기 버튼
- 메뉴 목록:
  - 학습 리포트 보기
  - 계정 설정
  - 도움말
  - 로그아웃
  - 회원탈퇴

---

## 5. 네비게이션 구조

```
홈 (대시보드)
├── 진행 중인 스토리 (1개) → 이어하기
└── 추천 스토리 (3개)

이야기
├── 스토리 목록 (카테고리 필터)
└── 스토리 상세
    └── 스토리 진행 (씬 도입 → 음성 인터랙션 → 다음 씬)

단어장
└── 학습 리포트 (어휘 탭 / 표현 탭 / 논리 탭)

마이페이지
├── 자녀 프로필 관리 (추가 / 수정)
├── 학습 리포트 보기
├── 계정 설정
├── 도움말
├── 로그아웃
└── 회원탈퇴
```

## 6. 기술 연동 포인트 (AI/Backend 관점)

| 기능 | 연동 필요 |
|------|----------|
| 음성 인식 | STT API 연동 |
| AI 응답 분석 | LLM 기반 발화 분석 및 후속 질문 생성 |
| 후속 질문 생성 | 씬 목표 + 아이 발화 컨텍스트 기반 프롬프트 |
| 캐릭터 대사 재생 | TTS 또는 사전 녹음 오디오 |
| 어휘 분석 | 씬 완료 시 LLM 기반 사용 어휘·표현 분석 |
| 학습 리포트 생성 | 스토리 완료 후 LLM 기반 어휘/표현/논리 종합 리포트 생성 |
